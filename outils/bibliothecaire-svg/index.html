      SVG acceptés et confidentialité

      Le traitement reste dans votre navigateur, sans envoi de vos SVG. Les aperçus sont des images isolées : le code n’est jamais injecté dans la page. Utilisez des SVG autonomes : scripts, événements, animations, HTML intégré, DTD et ressources externes sont refusés avec une explication. Les références internes (#id), dégradés, masques et styles internes simples sont acceptés.

      Le XML est normalisé sans modifier les valeurs : les attributs utilisent des apostrophes, les caractères spéciaux sont échappés et les commentaires XML sont retirés. Power Apps peut ne pas prendre en charge toutes les fonctions SVG visibles dans votre navigateur.

        3. Récupérez votre bibliothèque

        Syntaxe Power Fx

        Collez cette formule dans App.Formulas. Chaque champ contient le SVG brut, pas une URI d’image.

        Fichier Excel statique

        Le classeur contient un vrai tableau : une colonne par image (son nom en en-tête) et une ligne de SVG bruts. Importez ce tableau comme données statiques dans Power Apps si cette option est disponible dans votre Studio, puis utilisez "data:image/svg+xml;utf8," & EncodeUrl(First(NomDuTableau).Image1) dans la propriété Image.

        Limites Excel : 32 767 caractères par cellule et 16 384 colonnes. Aucun SVG n’est tronqué ; si une limite est dépassée, la formule Power Fx reste disponible.

        Bibliothèque temporaire : vos images ne sont pas sauvegardées dans le navigateur. Copiez la formule ou téléchargez le fichier Excel avant de recharger ou fermer cette page.
