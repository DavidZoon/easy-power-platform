Construction du thème Power Fx

1. Importez vos couleurs

Formats à détecter

Ajoute uniquement les nouvelles couleurs, sans écraser vos retouches. Aucune détection si tous les formats sont décochés.

Formats et limites de conversion
  • HEX : #RGB, #RGBA, #RRGGBB et #RRGGBBAA ; 0xRRGGBB et 0xRRGGBBAA. L’alpha est conservé sur 8 bits.
  • Power Fx : RGBA() avec valeurs numériques FR ou EN, ColorValue("…") et Color.Nom. Les variables et expressions calculées ne sont pas évaluées.
  • RGB et HSL : virgules ou syntaxe CSS avec espaces et « / » ; pourcentages et angles deg, rad, grad ou turn.
  • CMJN / CMYK : fonctions cmjn(), cmyk() ou device-cmyk(), avec quatre pourcentages ou fractions de 0 à 1. Conversion sRGB approximative sans profil d’impression ICC.
  • Les noms HTML / CSS sont les noms anglais standards. Dans un texte libre, un mot comme « red » sera aussi reconnu comme une couleur.
  • RAL Classic : codes comme RAL 5015, RAL-5015 ou RAL5015 ; 215 correspondances issues du nuancier libre ral-colors. Il s’agit d’approximations à l’écran, pas de valeurs RAL officielles pour fabrication. RAL Design et Effect ne sont pas pris en charge.

    2. Personnalisez le thème

    Cliquez sur le rectangle d’une couleur pour modifier son HEX, sa valeur RGBA ou sa transparence. Les couleurs identiques sont regroupées, quel que soit leur format.

    Importez vos couleurs ou ajoutez-en une manuellement pour commencer.

      3. Vérifiez les combinaisons

      Comprendre les scores de contraste

      Pour chaque fond opaque, le texte opaque au meilleur contraste est retenu. Seuils pour le texte courant : AAA ≥ 7:1, AA ≥ 4,5:1. La capsule A (≥ 3:1) est un repère pour le grand texte, pas un niveau WCAG officiel.

      4. Récupérez le code Power Fx

      Syntaxe Power Fx
      Propriété de destination

      Privilégiez App.Formulas pour définir votre thème. Avec des variables globales dans App.OnStart, les couleurs peuvent apparaître noires au démarrage tant que les variables ne sont pas initialisées. Bien démarrer avec les formules d’applications canevas — Microsoft Learn.

      Ajouter des couleurs de texte ?

      La palette ne contient aucune couleur de texte. Voulez-vous ajouter du noir pour les fonds clairs et du blanc pour les fonds sombres ? Vos couleurs de fond seront conservées.

      Le traitement s’effectue dans votre navigateur, sans envoi du texte ni stockage de votre saisie. Le code collé est lu comme du texte, jamais exécuté.
