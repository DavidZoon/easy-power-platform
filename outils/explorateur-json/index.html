Exploration JSON

Collez le corps ou les sorties complètes d’une action. Maximum : 2 millions de caractères, 10 000 nœuds et 80 niveaux. Les grands entiers au-delà de la précision JavaScript peuvent être arrondis : transmettez-les comme chaînes si leur valeur exacte est nécessaire.

Diagramme JSON

100 %

Sélectionnez un champ ou une valeur dans le diagramme.

Aucune donnée envoyée ni stockée. Les index [0], [1]… ciblent les éléments de cet exemple, pas tous les éléments d’une boucle. Pour une boucle, choisissez item() ou items() et collez le JSON d’un seul élément. Collez l’expression dans l’onglet Expression de Power Automate, sans @ ni @{…}.

D’où provient le JSON ?

Présélection selon la structure : body avec headers ou statusCode suggère outputs() et les sorties complètes ; sinon body(). Cette suggestion ne distingue pas une action d’un déclencheur : vérifiez et ajustez le choix.

Utilisez le nom interne présent dans le code du flux, par exemple Get_item ou Apply_to_each.
