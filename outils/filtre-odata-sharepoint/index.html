← Tous les outils

Collez la sortie de l’action SharePoint Obtenir les éléments (Get items) : les colonnes sont détectées automatiquement, puis vous combinez vos conditions avec des ET et des OU, comme dans l’éditeur de filtres d’une application pilotée par modèle.

1. Collez le JSON de sortie

Dans l’historique d’exécution du flux, ouvrez l’action « Obtenir les éléments », affichez les sorties brutes, puis copiez le JSON complet ou le contenu de body. Un ou deux éléments suffisent.

Collez les expressions Power Automate à proposer dans les champs de valeur, une par ligne (par exemple @{triggerBody()?['Title']}).

2. Construisez le filtre

Les champs apparaîtront ici après l’analyse du JSON.

3. Copiez la requête de filtre

    L’analyse s’effectue dans votre navigateur, sans envoi du JSON à un service externe. Les valeurs commençant par @{ (expressions Power Automate) sont conservées telles quelles. Les colonnes « Plusieurs lignes de texte » et « Métadonnées gérées » ne sont pas filtrables par OData : filtrez-les ensuite avec l’action « Filtrer un tableau ».
