Ce blog statique ne propose ni compte utilisateur ni formulaire de collecte de données.
La recherche s’exécute localement dans votre navigateur.

## Hébergement

GitHub Pages héberge ce site. GitHub peut traiter des données techniques, notamment
des adresses IP, pour assurer la sécurité du service :
[déclaration de confidentialité de GitHub](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement).

## Préférences locales

Le thème et, si la mesure d’audience est activée, votre choix de consentement sont
enregistrés dans le stockage local du navigateur. Aucune préférence n’est envoyée
à l’auteur du blog. Vous pouvez les effacer dans les paramètres de votre navigateur.

## Mesure d’audience Microsoft Clarity

{% if site.clarity_id != '' %}
Clarity est configuré sur ce site. Il n’est chargé qu’après votre consentement.
Il peut produire des statistiques, des cartes de chaleur et des enregistrements de
session, avec masquage strict du contenu. Ne saisissez aucune donnée personnelle
ou confidentielle dans les champs du site.

Le bouton « Gérer la mesure d’audience » du pied de page permet de refuser ou de
retirer votre accord. Un rechargement applique le retrait et empêche tout nouveau
chargement de Clarity. Le retrait ne supprime pas rétroactivement les données déjà
transmises ni nécessairement les cookies tiers ; utilisez aussi les réglages du navigateur.
{% else %}
Clarity est actuellement désactivé : aucun script de mesure d’audience Microsoft
n’est chargé.
{% endif %}

Pour en savoir plus : [confidentialité Microsoft](https://privacy.microsoft.com/fr-fr/privacystatement)
et [documentation Clarity](https://learn.microsoft.com/en-us/clarity/).
